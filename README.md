# ROS2 FishBot Learning Project

A hands-on ROS2 mobile robot learning project based on ROS2 Humble and Ubuntu 22.04.

## Environment

- Ubuntu 22.04
- ROS2 Humble
- Gazebo Classic
- RViz2

## Current Features

- FishBot URDF model
- Differential drive control
- LiDAR
- IMU
- Odometry
- TF
- Cartographer SLAM
- Map saving
- AMCL localization
- Nav2 navigation
- EKF sensor fusion
- Pure Pursuit controller
- Third-party Vector Pursuit controller integration

## Project Goal

This repository records my ROS2 mobile robot learning process, experiments, configurations, and controller integration work.

## Notes

Some components are based on or adapted from existing open-source FishBot projects.

Third-party controllers are credited to their original repositories.

Some learning code was developed with AI assistance and then integrated, tested, and modified in this project.
